# 休憩中のピクトグラムの動き

[Issue #12](https://github.com/jphacks/tkb_2603/issues/12)。2026-10-25にSVGとCSSで実装した。`Pictogram`の`kind`、運動の案内文、休憩ごとに1種類を選んで保持する流れは維持する。

## 動作

| 種類 | 周期 | 動かす部分 |
| --- | --- | --- |
| 背伸び | 5.6秒 | 両腕を下から142度まで上げ、肘を少し伸ばす。上で約0.9秒止め、ゆっくり戻す。胴体は2pxだけ持ち上げる |
| 肩回し | 5秒 | 肩→肘→手首→肩の3辺で三角形を作る。手のひらは肩に接したまま、肘の円運動に手首を連動させる。毎周の前後に0.5秒ずつ止まる |
| 左右にゆらす | 6秒 | 腕を上げた姿勢で、腰から上を左右9度ずつ傾ける。左右と中央で止まる間を入れる |

脚と足元の影は上半身の変形から分離した。背伸び・左右の動きはSVGの親`g`で関節の位置を決め、その子をローカル原点で回転させる。腕を横に開く途中の切れを防ぐため、SVGには左右14pxずつ余白を取り、描画枠を128×136pxにした。人物自体の縮尺と中央位置は維持している。

肩回しは、ユーザーの参考画像と3辺をつなぐ指定に合わせ、胴体から肘への上腕・肘から手首への前腕・手のひらから肩への辺を描く。動かない腕に見えていた固定の横線を外し、腕の起点を胴体へ直接つなぐ。3辺は同じパスの頂点を共有して閉じ、CSSの`d: path(...)`で肘と手首を一緒に変える。肩への接点は固定し、手首は肩から12px・上腕に対して55度の位置で追従させるため、三角形が潰れない。右側は左側を反転する。

腕を少し短くする指定に合わせ、肘の軌跡を元の88%に縮め、中心をさらに2px上へ寄せた。上腕・前腕は約1割短くなり、肘が最も下がる位置は約3.3px上がる。調整後の軌跡は半径8.8×13.2pxの楕円で、32分割し、角度にsmoothstepを適用して回り始めと終わりを緩める。静止した薄い矢印も軌跡に合わせて縮め、回転方向を示す。対象のChromeで補間・描画を確認した。[CSSのdプロパティ](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/d)

CSSの同一周期で各部位を合わせる。背伸びと左右は`ease-in-out`、肩回しは座標側に緩急を付けて`linear`で補間する。始点と終点を同じ姿勢にし、毎回の動作に静止区間を入れる。運動の進行をReactのstateや休憩タイマーの更新で駆動しないため、再描画でアニメーションを作り直さない。デモの時計の倍速にも動きの周期を連動させない。

`prefers-reduced-motion: reduce`では既存の共通ルールでアニメーションを止める。背伸びと左右の動作は腕を上げた静止姿勢、肩回しは両手を肩に添えた静止姿勢を表示する。色は`currentColor`と既存のテーマ変数を使う。

## 変更箇所

- [`src/ui/Pictogram.tsx`](../src/ui/Pictogram.tsx): 脚・胴体・肩・上腕・前腕を分離。
- [`src/ui/style.css`](../src/ui/style.css): 種類ごとの動作、間、回転軸、静止姿勢。

## 確認結果

- 拡張の既存92テスト、型チェック、本番ビルドが成功。
- Chromeの実寸プレビューで、各動作の1周期を121地点に分けて確認。脚の座標が変わらず、線の太さを含めて描画枠に収まる。
- 始点と終点の変形、および各動作の静止区間の変形が一致することを確認。
- 肩回しは121地点で肩への接点が固定され、肘が楕円を進み、手首が追従することを確認。3辺の閉じた接続と、三角形が潰れないことも確認した。固定の横線を取り除き、動画Bを更新した。
- 実際の`App`をShadow DOMに描画する確認用ページで、1440×900のライトと390×700のダークを確認。ピクトグラムがタイマー枠内に収まり、再描画前後で同じアニメーションと進行位置を保つ。
- 動きを減らす設定ではピクトグラムのCSSアニメーションが0件になる。
- 下の動画3本をChromeで再生・シークして確認。実サイトでの操作と、動きが何に見えるかの担当者レビューは別途行う。
