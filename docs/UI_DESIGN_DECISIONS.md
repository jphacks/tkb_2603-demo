# 作業モニターUIの変更と設計判断

`gaku/ui` から `main` へのレビュー用。参照画像は [design/](design/)、動かし方と現在の仕様は [DEVELOPMENT.md](DEVELOPMENT.md) に記載する。

## 変更の目的

ChatGPTでの作業を妨げずに負担の目安を確認し、本人が区切りを決めて休憩できるようにする。色味と休憩画面は参照画像を基準とし、以前の画面にあった全体の器・5項目・割合表示を組み合わせた。

## 決定事項

| 項目 | 採用した仕様 | 判断の理由 |
| --- | --- | --- |
| 詳細の配置 | 右側パネル。広い画面では会話側の幅を確保し、閉じると解除 | 会話を見ながら負担の内訳を確認できるようにする |
| 詳細の内容 | 全体の器と、読む量・判断・確認／検証・切替・作業時間の5項目をバーと％で表示 | 以前の画面の情報量を保つ。5項目の％は休憩後に負担をためた要因の構成比で、各項目の満杯度ではない。判断を取れない場合は「未計測」と表示する |
| 推移グラフ | 「推移を見る」に折りたたむ。超過値に合わせて縦軸を拡張 | 普段は画面を小さくし、必要なときに増減と数値の尺度を確認できるようにする |
| 通知 | 画面右上に「今○分休む」「区切りがついたら休む」の2択 | 入力を遮らず、開始時点を本人が選べるようにする |
| 区切り待ち | 作業と計測を続け、開始ボタンを残す。待機中は再通知・自動開始をしない | 本人が作業の区切りを判断する。従来の最短5分後からの自動区切り検出による開始待ちは採用しない |
| 自動タイマー | ユーザーが開始する方式へ統一。旧設定は他の値を保って通知方式として読み込む | 通知で選ぶ操作と、実際の休憩開始を一致させる |
| 休憩の開始ボタン | 小さく「区切りがついたら」、大きく「○分休む」。幅176px・高さ56pxが基本 | 押した結果を明示し、画面を占めすぎない大きさにする。分数は現在の負担と休憩時間の設定に連動する |
| ボタンの配置 | 入力欄全体の16px上に追従。見つからないときは下端から144px | 入力欄の伸縮・会話切替・画面サイズ変更でも入力欄に重なりにくくする |
| 注意の強弱 | 90%以上は黄色、100%以上は赤。休憩ボタンは背景、計測中表示は数値・リング・枠線で示す | 同じタイミングで注意を伝えつつ、休憩の操作を主役にする |
| 100%超過 | RFとUFの蓄積を継続し、120%などの数値を表示。バーとリングは100%で満杯にする | 休憩待ちで増えた負担を保持し、図形が表示領域からはみ出すことを防ぐ。詳細では赤いバーと超過メッセージを表示する |
| 小さい常駐表示 | 表示が80%未満なら「−」で40px四方の葉のアイコンに折りたためる。クリックで戻す。80%以上では数値を表示する | 通常の作業中の占有を減らし、負担がたまった時点では数値を見える状態にする |
| 折りたたみの保持 | ページを開いている間は本人の選択を保持し、80%未満に戻ると再び適用 | 詳細や休憩から戻るたびに折りたたみ直す操作を減らす。再読み込み・別タブへの保存は行わない |
| 休憩画面 | 参照画像に合わせた中央モーダル。分・秒タイマー、運動の案内、復帰メモ、終了確認 | 操作の再描画や倍速でも残り時間が戻らず、次の作業に戻れるようにする |
| 運動の種類 | 休憩開始時に背伸び・肩回し・左右にゆらすから1種類を選び、保存 | 休憩中の選択肢を減らし、再描画や他のタブでも運動と案内が変わらないようにする |
| 動きの改善 | 関節で分けたSVGをCSSで動かし、脚を固定。5〜6秒ほどの動作に静止区間を入れる | 肩・肘・腰の動きを見分けられるようにする。動きを減らす設定では静止。設計・検証・動画は [PICTOGRAM_MOTION.md](PICTOGRAM_MOTION.md) を参照 |

## 計算と互換性で注意すること

- 5要素の等重みの計算、蓄積速度、休憩時の回復速度は維持し、合計100の上限を外した。
- 数値と警戒色は整数表示に揃える。80%で常駐表示を戻すルールはUIの固定ルールであり、設定画面の通知しきい値とは独立している。
- 休憩時間は設定を反映し、従来どおり最大15分。大きく超過すると、休憩後も値が残る場合がある。
- 以前の上限で失われた超過分は復元できない。更新後の蓄積から100%超過を保持する。
- `waitingForUser` と運動の種類は任意フィールドとして追加し、旧保存データも読み込める。古い休憩データに運動の指定がなければ背伸びを表示する。
- APIキーや会話本文の保存方針は変更しない。UIへ渡す設定はAPIキーを除き、有無だけを含める。

## レビュー時の確認手順

1. `npm install` → `npm run build`。Chromeに `.output/chrome-mv3/` を読み込み、既に読み込んでいる場合は拡張とChatGPTのページを再読み込みする。
2. 80%未満で「−」から葉のアイコンに折りたたみ、クリックで数値に戻せることを確認する。詳細を開閉しても操作できること、80%以上で数値に戻ることを確認する。
3. 詳細で全体の器・5項目・未計測の表示を確認し、「推移を見る」を開く。明暗両テーマと入力欄を複数行にした状態で、配置を確認する。
4. 必要なら設定のデモ倍速を使い、通知の2択と開始待ちを確認する。待機中も数値が増え、90%以上は黄色、100%以上は赤、超過時は120%などを表示することを確認する。
5. 「○分休む」で表示された時間の休憩が始まり、運動と案内が1種類で固定されること、復帰メモ・終了確認・復帰後の操作を確認する。デモを使った場合は設定を元に戻す。

特に実際のChatGPTでの右側パネルと入力欄の配置、開始待ち中の別タブ操作、旧設定を持った状態での更新を確認してほしい。
