ひといき

AI とのやり取りの中身から「脳にかかる負担の目安」をためて、作業の区切りのいい瞬間に「ひと休み」を提案する拡張機能です。JPHACKS 2026 東京B「がくんとるーは」

何をするもの?

  1. AI とのやり取りから、読む量・判断を求められた回数・確認や検証(エラーとの格闘)・話題の切替・作業時間の 5 つを取ります
  2. 中身が重いほど速く、器に負担がたまります(時間だけでは決めません)
  3. 器が 80% を超えたら、生成中でも入力中でもない区切りのいい瞬間に、理由つきで休憩を提案します
  4. 休憩は自分で始めます。「戻ったらやること」を 1 行メモでき、戻るとそのメモが出ます

Chrome 版の入れ方

対応: ChatGPT(chatgpt.com。ログインして使ってください)。Claude(claude.ai)・Gemini(gemini.google.com)は試験対応です

  1. 上の「Chrome 版をダウンロード」で hitoiki-chrome.zip を保存し、ダブルクリックで展開する(フォルダができます)
  2. Chrome のアドレス欄に chrome://extensions と入れて開く
  3. 右上の「デベロッパー モード」をオンにする
  4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダ(中に manifest.json があるフォルダ)を選ぶ
  5. ChatGPT などを開くと、画面の右下(入力欄の少し上)に「計測中 0%」が出ます。開いていたタブは再読み込みしてください
  6. 最初に「会話の分類を使いますか?」という説明が出ます。「同意して使う」を押すと、判断も計測します

展開したフォルダは消さずに置いておいてください(消すと拡張も動かなくなります)。Chrome の起動時に「デベロッパー モードの拡張機能を無効にする」という案内が出ることがあります。そのときは「無効にする」を押さずに閉じてください。

VS Code 版の入れ方

  1. VS Code の拡張機能の画面(Cmd + Shift + X、Windows は Ctrl + Shift + X)で「ひといき」と検索する(発行者は koubeyapurin)
  2. 「インストール」を押す(初めてのときは「発行者を信頼しますか」と出るので、信頼する)
  3. 画面の右下(ステータスバー)に「ひといき 0%」が出れば完了です

Marketplace のページ。検索で出ないときは、上の「VS Code 版をダウンロード」で .vsix を保存し、Cmd + Shift + P →「Extensions: Install from VSIX...」で入れることもできます。

前に .vsix で入れた人は、拡張の一覧の「ひといき(VS Code 試作)」をアンインストールしてから入れてください(器は 0 から始まります)。

失敗したコマンドを数えるのは、ターミナル(シェル統合が有効なもの)とタスクで動かしたものです。ウィンドウは 1 つで使ってください。

使い方

場面すること
ふだんいつもどおり AI と作業するだけ。器の % と内訳が見られます
提案が出たらChrome: 「今○分休む」か「区切りがついたら休む」(後で右下のボタンから始める)
VS Code: 「今休む」「次の区切りで」「今回は不要」
休憩中タイマーとストレッチの案内が出ます。器が下がります。Chrome は休憩中の画面で、VS Code は休む前に「戻ったらやること」をメモできます
止めたいChrome は拡張の設定画面で計測を止められ、記録も消せます。VS Code は拡張を無効にします

データの扱い

  • 会話の本文は拡張に保存しません。記録は件数・文字数・時刻・操作だけで、パソコンの中にだけ残ります
  • 判断・確認・切替を会話の中身から読み取る機能(Anthropic の API を使う)は、API キー無しで使えます。初めて開いたときに出る説明で「同意して使う」を押すと、1 往復ごとに本文を中継サーバー経由で Anthropic の API に送ります(中継サーバーは本文を保存せず、ログにも残しません)。押さなければ何も送らず、エラーの貼り付けや会話の切替などの手がかりだけで動きます(「判断」は未計測になります)。同意は設定画面でいつでも取り消せます。自分の API キーで直接使うこともできます
  • VS Code 版は、エディタやターミナルの出来事だけを使い、外へは何も送りません
