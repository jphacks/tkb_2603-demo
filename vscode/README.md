# ひといき

AI と一緒に開発していると、生成されたコードを読む、コマンドやテストの失敗を直す、ファイルを行き来する、といった作業が続きます。**ひといき**は、こうした作業の中身から脳にかかる負担の目安をため、区切りのいいところで「ひと休みしませんか」と提案します。時間だけで鳴るタイマーではありません。

- 画面右下のステータスバーに「ひといき 42%」と、今の目安を出します
- 目安がしきい値(既定 80%)を超え、手が止まった区切りで、通知で提案します
- 休むかどうか、いつ休むかは自分で決められます

ブラウザで ChatGPT・Claude・Gemini を使う時の Chrome 版もあります。入れ方は [配布ページ](https://jphacks.github.io/tkb_2603-demo/) を見てください。

## 何から目安をためるか

| 要素 | VS Code から取るもの |
|---|---|
| 読む量 | 入力ではない、まとまった挿入(1 回 100 字以上。読む量に入れるのは 1 回 500 字まで)。補完の受け入れと貼り付けは区別しません |
| 確認・検証 | **タスクと、シェル統合が効いたターミナル**で動かしたコマンドが失敗した時(終了コードが 0 以外) |
| 切替 | 開いているファイルの切替(5 秒以内の行き来は数えません) |
| 作業時間 | 入力・切替・コマンドが直近 5 分にあったか |
| 判断 | VS Code では取れません(未計測)。そのぶん目安は遅めにたまります |

作業の中身が重いほど速くたまり、休憩のタイマーの間だけ下がります。3 時間作業が無いと、その日の区切りとして 0 に戻ります。

## 使い方

1. ふだんどおり作業します。ステータスバーの「ひといき ○%」にマウスを乗せると、今日の内訳が見られます
2. 提案が出たら、3 つから選びます
   - **今休む**: 戻ったらやることのメモ(空でもかまいません)を入れて、休憩を始めます。長さは目安に合わせて 10〜15 分です(設定で短め・長めにできます)。ストレッチを 1 つ案内します
   - **次の区切りで**: 今の作業を終えてから、ステータスバーの「休憩を始める」を押して始めます
   - **今回は不要**: 次の提案まで 15 分、30 分、60 分と間を空けます(押さずに通知が消えた時も同じです)
3. 休憩中は、ステータスバーに「ひといき 休憩中 あと 4:12」と残り時間が出ます。押すと休憩を途中で終えられます
4. 時間になると「おかえりなさい」の通知と、休憩の前に書いたメモが出ます

提案は、入力が 3 秒止まっていて、終わる種類のタスクもデバッグも動いておらず、VS Code の窓が前にある時にだけ出ます。`tsc --watch` のような終わらないタスクは邪魔をしません。

コマンドパレットの「ひといき: 今休む」で、提案を待たずに休むこともできます。

### 設定

| 設定 | 中身 |
|---|---|
| `hitoiki.threshold` | 提案する目安のしきい値(50〜95、既定 80) |
| `hitoiki.breakScale` | 休憩の長さ(短め 0.5 / 標準 1 / 長め 1.5) |
| `hitoiki.speed` | 開発・デモ用。時計を速めます。ふだんは 1 のままにしてください |

## データの扱い

- **外へは何も送りません。** ネットワークは使いません
- 保存するのは、目安の数値と休憩の状態(メモを含む)だけで、VS Code の拡張の保存領域(このパソコンの中)に置きます
- コードやコマンドの中身は保存しません。数えるのは、挿入の文字数・失敗した回数・切替の回数・時刻です

## 制限

- **ウィンドウは 1 つで使ってください。** ウィンドウごとに目安と休憩が別々に動きます(片方で休んでも、もう片方は目安をため続けます)
- Chrome 版とは、目安が別々です
- 判断(AI から選択や確認を求められること)は、VS Code では取れません
- 確認・検証として取れるのは、タスクと、シェル統合が効いたターミナルの終了コードだけです。Test Explorer で動かしたテストは取れません
- これは負担の目安で、疲れを測るものではありません。疲れの感じ方は、自分の感覚も大切にしてください

## デモ用のコマンド(デモ repo だけ)

`src/shared/flags.ts` の `DEMO` が true の時だけ、コマンドパレットに「ひといき(デモ): 器 0 から」「器 75% から」「休憩の直前」が出ます。器の状態を作るだけで、その後の計算は本物と同じです。
