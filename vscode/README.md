# ひといき(VS Code 試作)

Chrome 拡張と同じ計算(`../src/core/`)を、VS Code での作業の出来事で動かす試作です。器がたまり、区切りで「ひと休みしませんか」と提案し、休憩のタイマーの間だけ器が下がるところまで、Chrome 版と同じ流れで動きます。

## 取るもの

| 要素 | VS Code から取るもの |
|---|---|
| 読む量 | 入力ではない、まとまった挿入(1 回 100 字以上。読む量に入れるのは 1 回 500 字まで)。補完の受け入れと人の貼り付けは区別できません |
| 確認・検証 | **タスクと、シェル統合が効いたターミナル**のコマンドの終了コードが 0 以外のもの。Test Explorer で回したテストは取れません |
| 切替 | アクティブなファイルの切替(5 秒以内の行き来は数えません) |
| 作業時間 | 入力・切替・コマンドが直近 5 分にあったか |
| 判断 | 取れません(未計測)。そのぶん器は遅めにたまります |

## 試作の範囲

- 休憩の流れは Chrome 版と同じです。提案の通知に「今休む」「次の区切りで」「今回は不要」のボタンがあります
  - 今休む: 戻ったらやることのメモ(空でも可)を入れて休憩を始めます。長さは器に合わせて 10〜15 分(`hitoiki.breakScale` で短め・長めにできます)。ストレッチを 1 つ案内します
  - 休憩中: ステータスバーに「ひといき 休憩中 あと 4:12」。押すと休憩を途中で終えられます。休憩のタイマーの間だけ器が下がります
  - 終わったら「おかえりなさい」の通知と、メモを出します
  - 次の区切りで: ステータスバーの「休憩を始める」を押した時に始めます
  - 今回は不要・押さずに消えた時: 次の提案まで 15 → 30 → 60 分空けます
- コマンドパレットの「ひといき: 今休む」で、提案を待たずに休めます
- 休憩中に VS Code を閉じても、開き直すと閉じていた間のぶんタイマーが進みます
- 休憩の記録(Chrome 版の「どうだった?」や記録の書き出し)はありません
- **ウィンドウは 1 つで使ってください。** ウィンドウごとに器が動き、休憩も別になります(片方で休憩しても、もう片方は器をため続けて提案を出します。両方で休憩すると、おかえりも 2 回出ます。保存は最後に書いた方が残ります)。Chrome 版の器とも別です
- 提案を出すのは、入力が 3 秒止まり、終わる種類のタスクもデバッグも動いておらず、VS Code の窓が前にある時です。`tsc --watch` のような終わらないタスクは邪魔をしません

## 動かし方

1. `npm install`
2. VS Code でこの `vscode/` フォルダを開き、F5(「ひといき(拡張機能の開発ホスト)」)
3. 開発ホストの設定で `hitoiki.speed` を 60〜120 にすると、1 秒で計算上 1〜2 分進みます
4. 失敗するコマンドやタスクを何回か動かすと、右下の「ひといき n%」が上がり、しきい値(`hitoiki.threshold`、既定 80)を超えると、区切りで提案が出ます

## デモ用のコマンド(デモ repo だけ)

`src/shared/flags.ts` の `DEMO` が true の時だけ、コマンドパレットに「ひといき(デモ): 器 0 から」「器 75% から」「休憩の直前」が出ます。器の状態を作るだけで、その後の計算は本物と同じです。

## 確かめ

- `npm test`: 出来事 → 計算の変換(VS Code の API をまねた形)
- `npm run e2e`: インストール済みの VS Code を使い捨てのプロファイルで開き、倍速で失敗するタスクを繰り返して、提案 → 今休む → 休憩が終わって器が下がる → おかえり、までを確かめます(ボタンは拡張の口から押します)。VS Code の窓が 1 分ほど画面に出るので、その間は触らないでください
